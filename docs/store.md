# 商店

侧栏 **商店** 里可以浏览、搜索并安装插件和技能。

## 安装流程

1. 点 **安装**。应用先下载安装包，核对目录里登记的 SHA-256，解压到暂存区。
2. 弹出确认框，列出这个包**实际**能做什么（从包里的文件读出，不是商店的自我介绍）。
3. 点 **确认安装** 才会落盘；点取消或关闭窗口，暂存的包会被丢弃。

确认框里的能力分三档：高风险（拦截后端命令的 WASM、在 OpenCode 里运行的脚本、修改 MCP 或权限的配置补丁、界面脚本）、中风险（追加提示词、附带可执行脚本、界面内容）、低风险。

## 技能

技能装在应用数据目录的 `skills/` 下，所有工作区共用，由 OpenCode 原生的 `skill` 工具按需加载。停用技能不会删文件，只是给它加一条 `permission.skill` 拒绝规则。技能名必须是小写字母、数字和单个短横线，并与目录同名。

## 商店目录格式

商店是一个 JSON 文件，默认地址可在商店页底部修改（只接受 https；本机测试可用 `http://127.0.0.1`）。

```json
{
  "items": [
    {
      "id": "reviewer",
      "kind": "plugin",
      "name": "代码审查",
      "description": "审查改动并给出意见",
      "version": "1.2.0",
      "author": "Moyu",
      "tags": ["review"],
      "url": "packages/reviewer-1.2.0.zip",
      "sha256": "64 位十六进制"
    }
  ]
}
```

- `kind` 是 `plugin` 或 `skill`。`id` 对插件遵循 plugin.json 的规则，对技能遵循技能命名规则。
- `url` 可以是相对目录文件的路径；最终必须是 https。下载最多跟随 5 次重定向，且每一跳都必须是 https。
- 无效条目会被跳过，不会让整个目录失败。
- 安装包是 zip，可以带一层顶层文件夹。包里的 `plugin.json` 的 `id`（或 `SKILL.md` 的 `name`）必须与目录里的 `id` 一致。

## 安装包的限制

zip 最大 32 MiB，解压后最大 64 MiB，单个文件最大 8 MiB，最多 1000 个文件。含 `..`、绝对路径、盘符、反斜杠、`.git`、Windows 保留名或符号链接的包会被整体拒绝。名字属于内置插件的包不能替换内置插件。
